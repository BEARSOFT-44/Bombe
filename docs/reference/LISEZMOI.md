# Documents de référence

|---|---|---|

Utile pour retrouver à quelle patte du microcontrôleur correspond chaque broche. | © Arduino. Les schémas de référence Arduino sont publiés sous licence [Creative Commons BY-SA](https://creativecommons.org/licenses/by-sa/2.5/). Fournis « tels quels », sans garantie. |
| `arduino-projects-book.txt` | Texte de l'*Arduino Projects Book*, le livret du Starter Kit : bases de l'électronique et 15 projets guidés. Extrait en texte brut du PDF d'origine, donc sans les images. | © 2012 Arduino LLC, texte de Scott Fitzgerald et Michael Shiloh. Licence [Creative Commons BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/) : réutilisation autorisée **sans but commercial**, en citant l'auteur, et sous la même licence. |
